## Goal
Get Meet Sojitra interviews for **Full Stack / Backend-leaning Python & React roles**.
The portfolio should load fast, look distinctive but professional, and make contacting him effortless.

> Full Stack Developer building APIs and React interfaces with Python, Django, and FastAPI. Currently shipping AI-assisted products.

## Primary CTAs (in priority order)
1. **Email me** (`meetsojitra314@gmail.com`)
2. **Download resume** (PDF)
3. View live projects / GitHub

## Why this reference layout works for a job search
The reference is a numbered, bordered-grid, one-page site. We keep the *structure and feel* and adapt the *purpose*:

| Reference section (freelancer) | Our section (job seeker) | Change |
|---|---|---|
| Hero: "full-stack web developer_" + featured project card | Hero: simple, centered typed headline over a faint code-themed background (no project card, no 3D) | Status badge says "Open to full-time roles" |
| Selected projects (6, alternating image/text) | Selected projects (2, alternating) | Only PickWise and BugSence, each given a larger, richer row |
| About + stats + logo tile | About + stats + "MS" monogram tile | Stats come from the resume only |
| Services (3 cols) | **Skills / What I do** (3 cols) | Backend · Frontend · Data & Tools |
| Process (4 steps) | **How I work** (4 steps) | Short, honest, engineering-focused |
| Pricing (4 tiers) | **Experience** (timeline of 2 roles) | Pricing removed; this is not a freelance site |
| "have a project in mind?" footer CTA | "Let's talk" footer CTA | Email, GitHub, LinkedIn |

## Site map (single page, anchor nav)
`Projects · About · Skills · Experience · Contact` + **Resume** button + theme toggle.
No language switcher (English only).

## Section order
1. Hero
2. Selected Projects
3. About
4. Skills ("what I do")
5. How I work
6. Experience
7. Education & Certifications (compact, one bordered row)
8. Contact CTA + Footer

## Success criteria
- A recruiter understands who Meet is, what stack he uses, and how to reach him **within 10 seconds** of landing.
- Resume downloadable in **one click** from the header and the hero.
- Every project card links to something real (live + GitHub).
- Mobile layout is as good as desktop (most recruiters open links on phones).

## Out of scope
Blog, CMS, auth, pricing, multi-language, analytics beyond a privacy-friendly page-view counter (optional), contact form with backend (use `mailto:` — simpler and more reliable).
