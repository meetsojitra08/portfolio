# Meet Sojitra — Portfolio Website

A responsive React + TypeScript + Vite portfolio inspired by the supplied editorial/minimal developer portfolio references.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Customize before publishing

1. Replace the generic GitHub and LinkedIn destinations in `src/App.tsx` with your actual profile URLs.
2. Replace the project GitHub links and add live project URLs/case-study pages when ready.
3. Confirm the experience dates and wording are current before publishing.
4. Add a downloadable resume link if you want visitors to download your PDF.
5. Update the page title and description in `index.html` if desired.

## Included

- Responsive desktop, tablet and mobile layouts
- Light/dark theme toggle
- Sticky navigation and mobile menu
- Hero, projects, about, experience, skills, services, education, certifications and contact sections
- CSS-built project preview artwork (no external image dependencies)
- Email contact links

All project descriptions and career details are based on the supplied resume. Visual project mockups are illustrative UI artwork, not screenshots of the actual applications.
